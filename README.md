# ncblab_web

## 安裝步驟

下載後在終端機依序輸入：

### 1. 前端 Vue

```bash
npm install axios
```

### 2. 後端 Flask

```bash
pip install flask flask-cors
```

---

## 本端測試

### 開啟終端機1：啟動後端

```bash
cd backend
pip install -r requirements.txt
python main_api.py
```

---

### 開啟終端機2：啟動前端

```bash
cd frontend
npm run dev
```
